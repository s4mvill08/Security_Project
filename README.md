# SENTINEL

Proyecto académico de diseño e implementación de una plataforma para gestionar incidentes de seguridad.

## Aplicación web

La aplicación React y la configuración de Supabase están en [stitch_sentinel_incident_response_platform](./stitch_sentinel_incident_response_platform/).

Consulta su [manual y guía de desarrollo](./stitch_sentinel_incident_response_platform/readme.md) para instalar dependencias, iniciar Vite y configurar la base de datos.

Los directorios de pantallas en la raíz conservan los prototipos visuales de referencia.
